# 桌面小工具

一个轻量的 Windows 桌面悬浮工具，用浏览器 `--app` 模式运行，无需安装任何环境。

## 功能
- **便签**：随手记，本地保存，关闭不丢
- **倒计时**：正计时 / 暂停继续 / 重置，最后 10 秒变红
- **剪贴板**：自动记录复制内容，点击回填
- **待办**：添加、勾选完成、删除
- **速算**：四则运算 + 常用单位换算

## 使用方法
双击 `启动小工具.bat` 即可启动。

- 按住窗口**顶部**拖动位置
- 右上角 `✕` 关闭
- 数据存在本地（localStorage），不会丢失

## 文件说明
- `index.html` — 界面
- `app.js` — 逻辑与数据存储
- `启动小工具.bat` — 一键启动器
