# 桌面宠物 🐳→👧

透明背景、无边框、置顶的桌面宠物，点一下它就跳一下。当前是**黑发二次元小女生**形象。

## 当前版本：黑发小女生
- 黑长直发 + 齐刘海 + 粉色蝴蝶结发饰
- 大眼、腮红，萌系 Q 版大头
- **点一下 → 跳一下 + 笑**；偶尔眨眼；可拖动；右键退出

## 使用方法
- 双击桌面「小女生宠物.vbs」启动（静默，无黑框）
- 已配置开机自启
- 右键宠物 → 退出

## 文件说明
- `GirlPet.ps1` — 当前小女生版主程序
- `WhalePet.ps1` — 旧的小鲸鱼版主程序（保留）
- `启动小女生.vbs` — 小女生启动器
- `启动小鲸鱼.vbs` — 小鲸鱼启动器
- `index.html` / `pet.js` — 最早的网页版（功能最全）

## 想换回小鲸鱼
把 `启动小女生.vbs` 里指向的 `GirlPet.ps1` 改成 `WhalePet.ps1` 即可。

## 关键注意事项（开发备忘）
- PowerShell 5.1 读 `.ps1` 必须 **UTF-8 with BOM**，否则中文/emoji 乱码报语法错
- 运行需 `-ExecutionPolicy Bypass`
